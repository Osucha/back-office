Top solution: RateLimiter keeps immutable Bucket(tokenNanos, updatedAt) per key in a ConcurrentHashMap and updates it with compute() (atomic per key); tokens are stored as integer token-nanoseconds (1 token = refillPeriod in ns), so fractional refill is exact; retryAfter = periodNanos - available. evictIdle() removes buckets with computeIfPresent(... full ? null : bucket) so it cannot race with tryAcquire; tryAcquire triggers evictIdle at most once per capacity * refillPeriod. RateLimitProperties record (@ConfigurationProperties("petclinic.rate-limit"), @DefaultValue 20 / 3s); RateLimitConfiguration (@Configuration, not a @Component filter, so @WebMvcTest slices stay unthrottled) creates RateLimiter with the system clock (or a Clock bean) and a FilterRegistrationBean for /owners and /owners/*; RateLimitFilter extends OncePerRequestFilter, shouldNotFilter for non-POST or paths other than /owners and /owners/..., 429 + Retry-After = ceil(seconds), min 1.
Pitfalls to penalise: synchronized on the whole limiter (works but scales poorly), double arithmetic without care for rounding, eviction that removes partially used buckets (resets limits) or never runs, a @Component filter that breaks or throttles @WebMvcTest tests, keying on X-Forwarded-For without a trusted proxy, sleeps in tests. A @SpringBootTest placed in package system.* picks up the nested @SpringBootApplication of CrashControllerIntegrationTests unless classes = PetClinicApplication.class is set (the reference test does that).
Hidden tests: RateLimiterAcceptanceTests (unit, MutableClock: burst 3 -> remaining 2/1/0 then deny retryAfter 3s; fractional refill 1s/1.5s/0.5s; floor of remaining; cap after 2 days; denied calls do not consume; independent keys; eviction counts 2 -> 1 -> 0 and a fresh bucket afterwards; constructor validation; 16 threads x 200 calls on capacity 1000 admit exactly 1000, never negative remaining; durations compared with +-1 ms), RateLimitHttpAcceptanceTests (capacity 2, refill 1h: third POST 429 with Retry-After 3500-3600; GETs never limited; per-IP buckets; /owners/new, /owners/1/edit, /owners/1/pets/new and visits share one bucket; POST /ownersearch and /vets.html not limited), RateLimitDefaultsAcceptanceTests (defaults: first 429 on attempt 21 or 22, Retry-After 1-3).
